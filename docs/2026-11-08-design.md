# Pi 多语言包 · 设计

日期：2026-11-08
状态：已实现，副本与正式安装验收通过（2026-11-08）

> 验收记录（实测）：正式安装目录已打补丁（Pi Network 0.6.4，词表 600 条）；
> 界面中文截图见 `docs/screenshots/`；模拟官方更新（用原始 asar 覆盖）后 10 秒内
> 守护自动重打（日志「守护自动重打：已安装中文补丁」）；还原英文后守护不再打回；
> 中英语言切换可用；开机自启已设置（HKCU Run，指向本工具的 exe）。

> 审阅后追加的实现级决定：
> - **守护状态机**（解决「还原后被打回」）：config 记 `desiredState`（zh / restored /
>   paused）+ 补丁后 asar 指纹。守护只在 `desiredState=zh` 且 asar 无补丁标记时重打；
>   用户点「还原」= desiredState 改 restored，守护不再打。官方更新后仍按 desiredState
>   恢复，保证「永远中文」与「可还原」不打架。
> - **词表与版本不匹配**：照打，但安全优先——所有词条只做**整句精确匹配**（不做模糊/
>   正则套用）；危险操作类词条另加 `danger: true` 标记，新版上找不到精确匹配就不翻、
>   保留英文。托盘提示「应用已升级到 x.x.x，建议更新词表」。
> - **验证策略**（副本启动会撞单实例锁，原「直接启动副本」不成立）：停掉 Pi Node 与
>   Pi Guard 后，复制整个安装目录、exe 改名（避开 Pi Guard 的进程名匹配）、对副本
>   asar 打补丁，用 `--remote-debugging-port` + CDP 读回页面文本验证中文生效，再关掉
>   副本；正式安装目录在验证通过前不动。
> - **多语言切换**：注入脚本内联全部语言包；托盘切语言 = 重打 asar + 提示重启 Pi Node
>   生效（注入脚本无 Node 权限，运行时读不到外部配置，这是最简可靠做法）。

## 1. 它是什么

给 Pi Node 桌面版（Pi Network Desktop，当前 v0.6.4）装界面中文的独立小软件。
装一次后，每次打开都是中文；官方自动更新换掉 `app.asar` 后，它会在后台自动重新
打上补丁，用户不用再操作。词表按"多语言包"组织：内置简体中文，以后加繁体/英文/
日文只加一份词表、在托盘里切。

**不与 Pi 守护框（PiGuard）合并**，独立进程、独立配置、独立托盘图标，各跑各的。

## 2. 技术事实（决定了方案）

- Pi Node 是 Electron 套**本地** React + MUI 界面，界面文字硬编码在
  `resources\app.asar` 的 `dist/renderer/renderer.js` 里，**没有 i18n 框架、没有语言设置**。
- 官方自动更新（`downloads.minepi.com`）会整体替换 `app.asar`——任何"只改一次文件"
  的做法都会在下一次更新后失效，所以必须有守护重打。
- 安装包带完整 sourcemap，能还原 198 个业务源码文件、约 700 条用户可见文案——词表
  可以照着源码做，不漏。
- Windows 下 Electron 不校验 asar 完整性（`app.asar` 无签名校验 fuse 生效），改 asar
  可以正常加载——**用副本启动一次验证后才动真安装目录**。
- 主界面文字全部由本地 React 渲染成 DOM，运行时按词表替换文本可行，不碰业务逻辑。

## 3. 目标 / 非目标 / 反目标

**目标**
- 打开 Pi Node 就是简体中文；官方更新后自动恢复中文，零操作。
- 多语言词表独立成包，加语言只加词表。
- 可一键还原英文原版。
- 机房多台机器拷贝即用（免运行时 exe）。

**非目标**
- 不翻译内嵌 webview 里的远程 Pi 应用。
- 不翻译服务端下发的通知正文（标题可）、日志、命令输出、崩溃堆栈。
- 不改 `Pi Network.exe`，不改官方签名，不碰官方更新机制。
- 不做官方源码级语言切换（构建链不在包里，不现实）。

**反目标**（做到就算失败）
- 汉化后节点功能异常（Docker、端口检查、区块链数据操作）。
- 危险按钮被翻错（"移除区块链数据"等），导致用户误操作。
- 更新后留下坏 asar，Pi Node 打不开。

## 4. 方案（已选，另两个已排除）

- **运行时词典注入 + 常驻守护（选它）**：改 asar 只加一个脚本 + 改 index.html 一行；
  词表替换 DOM 文本；守护进程在官方更新后自动重打。改动小、可逆、可多语言、能跟版本。
- 静态替换 asar 里的英文字符串（排除）：一次性、无法多语言、每个版本重新匹配、改错难查。
- 从 sourcemap 还原源码重编译成官方 i18n 版（排除）：构建链不在包里，要自己重建，
  且每次官方更新都要跟，维护成本极高。

## 5. 部件

1. **AsarEditor**（纯 C#）：asar 读写（pickle 头 + JSON 索引 + 数据区），支持就地注入/
   移除文件和原子替换。
2. **Injector**：生成 `dist/renderer/pi-lang.js`（内联语言包 + DOM 翻译引擎），并让
   `index.html` 加载它；同时写补丁标记。
3. **LangPack**：多语言词表 JSON。内置 zh-CN 种子，首次运行释放到
   `%APPDATA%\PiLang\langs\`，之后可直接替换/新增。
4. **Guard**：常驻轮询（每 2 秒）检查 `app.asar` 补丁标记，发现被官方更新覆盖就
   自动备份 + 重打 + 托盘提示。
5. **Tray UI**：状态（已汉化 v0.6.4 / 未汉化）、安装、还原英文、语言选择、开机自启、
   打开配置目录。
6. **CLI**：`--ensure` / `--install` / `--restore` / `--status`，供任务计划和排障用。

## 6. 注入脚本设计

- 加载顺序：`index.html` 里放在 `renderer.js` 之前。
- 翻译对象：Text 节点、`input/textarea` 的 placeholder、`title` / `aria-label` / `alt`、
  button/option/label 文本。
- 匹配顺序：整句精确 → 归一化（去首尾空白）→ 正则模板（带数字/版本号的动态句）→
  不命中就保留英文。
- 动态内容：MutationObserver（100ms 节流）兜底；React 重渲染覆盖后自动再翻。
- 防循环：已含中文的节点跳过；只处理含拉丁字母的文本。
- 语言切换：注入脚本内联全部语言包，按配置选定 locale；托盘切语言 = 用新 locale
  重打一次，重启 Pi Node 生效（注入脚本无 Node 权限，运行时读不到外部配置）。
- CSP：`index.html` 的 CSP 允许同源脚本，无需改。

### 6.1 原生控件（已解决，2026-11-08 追加）

- **原生菜单栏**（文件/视图/帮助、托盘右键）和 **window.confirm 确认弹窗正文**
  不在 DOM 里，DOM 注入改不到。解决方式：安装时对 asar 里的 `dist/main/main.js`
  （菜单 label）和 `dist/renderer/renderer.js`（confirm 消息字符串）做**字符串常量替换**，
  不动逻辑；还原时用整包备份恢复。
- 中文字体：注入脚本补一段 CSS，给 body 字体栈加 `Microsoft YaHei` 回退，避免中文
  落到宋体。
- 动态时间（"1 minute ago"）用正则模板翻译；数字、版本号等动态部分保留原样。
- 内嵌 webview（Pi 应用）与服务端通知正文翻不了。

## 7. 词表

- 从还原源码提取约 477 条用户可见文案（另有 28 条长法律条款单独处理），逐条翻译；
  危险操作、报错文案单独人工校对。
- 格式：`{ "version": "0.6.4", "name": "简体中文", "entries": {...}, "patterns": [...] }`
- 后续补词条：替换 `langs\zh-CN.json` 后重打一次；不重编译 exe。

## 8. 文件与目录

```
%APPDATA%\PiLang\
  config.json          locale、安装路径、desiredState(zh/restored/paused)、
                       guardEnabled、autoStart、lastPatchVersion、appliedAsarHash
  langs\zh-CN.json     多语言包（可替换/新增；条目可带 danger 标记）
  backup\app.asar.0.6.4.orig
  PiLang.log
```

## 9. 官方更新后的行为

守护每 2 秒看 `app.asar`：`desiredState=zh` 且补丁标记消失且是合法 asar → 判定被更新 →
备份新原版 → 自动重打 → 托盘提示"新版 x.x.x 已自动汉化，重启 Pi Node 生效"。
`desiredState=restored` 时守护什么都不做；`paused` 时守护暂停。
新版若改了目录结构（index.html 路径变了）→ 不硬来，回滚到备份并记录日志报警。
Pi Node 正在运行时重打 → 提示重启应用才生效。

## 10. 安装 / 备份 / 还原

- 定位安装目录：配置 → 注册表卸载项 `DisplayIcon` → 默认路径。
- 写 asar 用临时文件 + 替换；失败自动用备份回滚。备份保留最近 3 个版本防膨胀。
- 还原：优先"就地移除注入"（不依赖备份），失败再用备份。

## 11. 验收标准

1. 新装：双击 → 安装中文 → 启动 Pi Node → 主界面中文。
2. 模拟官方更新（用原版 asar 覆盖）→ 5 秒内自动重打 → 重启应用仍是中文。
3. 还原英文 → 界面恢复英文，应用正常运行。
4. 切语言：en-US 显示英文，切回 zh-CN 显示中文。
5. 功能自检：节点状态、设置、端口检查、危险操作弹窗用词正确；无 JS 报错。
6. 开机自启：重启电脑后守护自动工作。

## 12. 风险与应对

| 风险 | 应对 |
|---|---|
| 重打包 asar 后 Electron 拒绝加载 | 副本验证（改 exe 名避开 Pi Guard、CDP 读页面文本），失败不动正式安装目录 |
| 词表漏翻（个别英文残留） | 不伤功能；补词条即可 |
| 官方新版目录结构变化 | 守护回滚 + 托盘报警，不硬来 |
| 危险按钮翻译不当 | 词条整句精确匹配 + danger 标记，新版匹配不上就不翻 |
| 还原后被守护自动打回 | desiredState 状态机（restored 时守护不打） |
| 自包含 exe 被杀软误报 | 说明里写清楚；不写敏感注册表项 |
