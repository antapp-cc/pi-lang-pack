Pi 多语言包 · 使用说明

【它做什么】
把 Pi Node 桌面版（Pi Network Desktop）的界面变成简体中文。
装一次后，每次打开都是中文；官方自动更新替换界面文件后，它会在后台自动
重新打上中文补丁，不用你手动操作。
这是一个独立的托盘小工具，和 Pi 守护框互不相干，各跑各的。

【怎么用】
1. 双击  Pi多语言包.exe  （免运行时版，约 50MB，拷到别的电脑也能直接双击）
   或者  依赖运行时版\PiLang.exe  （约 0.3MB，需要电脑装 .NET 10 桌面运行时）
   启动后系统托盘出现蚁巢图标。
2. 右键托盘图标，菜单里可以：
   - 看当前状态（已汉化 / 未汉化，附 Pi Network 版本号）
   - 安装中文补丁
   - 还原英文原版
   - 语言：简体中文 / English（切换后需要重启 Pi Network 生效）
   - 开机自动启动（首次使用已默认打开）
   - 打开配置文件目录 / 打开日志
   - 退出
3. 装完补丁后启动（或重启）Pi Network，界面就是中文。

【官方更新了怎么办】
不用管。程序常驻时会盯着 interface 文件（app.asar），官方更新覆盖后自动重打，
托盘会弹提示"检测到 Pi Network 更新，已自动重新汉化"。重启 Pi Network 就是中文。
所以这个程序要一直开着（已配开机自启）。

【装补丁前注意】
Pi Network 必须完全退出（托盘图标也退掉）。正在运行时点"安装中文补丁"会提示
先退出——这是为了避免写文件时把正在用的界面文件写坏。

【配置文件】
%APPDATA%\PiLang\
  config.json                   语言、期望状态、自动重打开关
  langs\zh-CN.json              中文词表（可自己改/补，改完点一次"安装中文补丁"）
  backup\app.asar.0.6.4.orig    原始界面文件备份（还原用，留着别删）
  PiLang.log                    运行日志
右键托盘图标 → "打开配置文件目录" 可以直接打开。

【词表】
内置简体中文 600 条，覆盖应用自己的界面（侧边栏、按钮、设置、提示、弹窗等）。
已额外处理的原生控件（不在网页里、靠改应用资源实现）：
- 窗口菜单栏（文件 / 视图 / 帮助）和托盘右键菜单
- 危险操作的确认弹窗正文（"你确实要删除所有区块链数据吗？"等）
翻不了的地方（先说清楚）：
- Pi 应用里嵌的远程网页（webview 内容）
- 服务器下发的通知正文
- 日志、命令行输出、程序报错堆栈
漏翻的词条可以打开 langs\zh-CN.json 补：键是英文原文，值是中文，改完点
"安装中文补丁"重打一次即可（不用重新编译 exe）。

【兼容性】
- Pi Network Desktop 0.6.4 已验证通过；其它版本会尝试适配，结构对不上会自动
  回滚到备份并在日志里报警，不会把应用弄坏。
- 支持 Windows 10 / 11（x64）。
- 免运行时版是自包含 exe，个别杀软可能误报，加信任即可。

【注意】
- 挪了这个文件夹后，开机自启记的还是旧路径：把托盘菜单里"开机自动启动"取消
  再勾选一次。
- 想彻底卸载：右键托盘"还原英文原版"，退出程序，删掉这个文件夹和
  %APPDATA%\PiLang 即可。
- 日志在 %APPDATA%\PiLang\PiLang.log，出问题先看它。


【在线更新】
程序会自动检查更新：启动后约 15 秒检查一次，之后每 6 小时一次；右键托盘
「检查更新」也可以手动查。更新源地址在 %APPDATA%\PiLang\config.json 的
updateUrl 字段，默认 https://raw.githubusercontent.com/antapp-cc/pi-lang-pack/main/server/latest.json。
- 词表更新：自动下载并重新汉化（如果 Pi Network 正开着，会等你关闭后自动补上）；
- 程序更新：自动下载、退出、替换、重启；旧版本保留为 程序名.exe.old。
- 安全：只接受 https 地址（本地测试允许 localhost），下载内容必须与清单里的
  SHA256 一致，不一致直接拒绝更新。
- 服务器端目录需要三个文件：latest.json、zh-CN.json、PiLang.exe
  （GitHub 仓库的 Releases 和 server 目录维护，详见 README）。
- 关掉自动检查：把 config.json 的 autoUpdate 改成 false。
